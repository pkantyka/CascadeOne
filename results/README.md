# Community run registry

All contributors — maintainers included — submit results under results/runs/<run-id>/. There is no special "reference" class or separate "community" class.

A submitted run should contain manifest.json, environment.json, measurements.jsonl, telemetry.jsonl, summary.json and SHA256SUMS generated by the same runner. Use tools/validate_result.py before opening a PR. Treat the run as immutable; corrections require a new ID and documented supersession.

The first Engineering Preview includes no new GPU runs. Historical results are described in docs/development-evidence and explicitly not presented as v0.1 reruns.

Comparisons require matching model revisions, dataset hash, routing policy and inference settings, and should separate strong-alone memory measurements from colocated latency. No public results browser is shipped yet.
